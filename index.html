Questions Fréquentes
Comment saisir un trade ? +
Allez dans l'onglet Saisir un Trade depuis la barre latérale gauche. Remplissez les champs (actif, direction, SL, TP, volume) et cliquez sur Ajouter le Trade.
Où sont sauvegardées mes données ? +
Vos données sont synchronisées de façon sécurisée sur tous vos appareils via l'API de stockage persistante BNV. Connectez-vous avec votre compte depuis n'importe où pour retrouver vos trades.
Comment calculer mon Consistency Score ? +
Le Consistency Score Pratique est calculé automatiquement à partir de vos trades. Il compare la régularité de vos résultats avec votre objectif de Consistency Théorique défini dans la configuration.
Comment exporter mes trades ? +
Dans Paramètres, section Données, cliquez sur Exporter (CSV). Vous obtiendrez un fichier CSV compatible avec Excel, Google Sheets, etc.
Puis-je utiliser le journal sur plusieurs appareils ? +
Oui. Vos données sont enregistrées dans le cloud, sous votre compte : connectez-vous avec la même adresse e-mail sur un autre ordinateur ou un téléphone pour retrouver votre journal.
